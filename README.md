# UniPay — практические работы по ООП

Публичный репозиторий для самостоятельного получения лабораторных по номеру.

Здесь публикуются только открытые преподавателем стартовые работы и инструмент их получения. Эталоны, преподавательская история Git и ещё не открытые номера сюда не переносятся.

Инструмент получения и первый номер готовятся в отдельном pull request. Студенты работают в собственных репозиториях, не в этом репозитории.
